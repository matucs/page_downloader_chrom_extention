What it finds

It scans the page you're on and lists every downloadable file, including the ones a right-click misses — lazy-loaded images, CSS background images, and picture sources.

Images Video Audio PDF & Office docs Archives Subtitles HLS & DASH manifests

How it works

  1. Open any page and click Scan Page.
  2. Filter by file type and select what you want.
  3. Download one file, a selection, or everything at once.

Features

  • Bulk selection with type filters
  • Pause, resume and cancel mid-batch
  • Subfolders by type (images/, videos/)
  • Mirror the site's folder structure
  • Timestamp or site name in filenames
  • Custom download folder
  • Automatic duplicate skipping
  • Downloads continue after the popup closes
